# مرحباً بكم في منصة EidCloud

**eidcloud-site-gen** هو مولد مواقع ومستندات ساكنة ثنائي الاتجاه (Bi-Directional LTR & RTL) فائق السرعة تم بناؤه بلغة PHP الصافية 8.2+ دون أي اعتماديات خارجية.

## أبرز المزايا

- **سرعة فائقة**: بناء مئات الصفحات والمستندات في أقل من 50 مللي ثانية.
- **دعم أصيل للغة العربية (RTL)**: تجربة خالية تماماً من أخطاء تخطيط الواجهات.
- **محركات بحث وSEO متكامل**: خرائط مواقع XML وOpenGraph وبيانات Schema.org المنظمة.
- **معايير الوصولية WCAG 2.1 AA**: هيكل HTML دلالي يمكن تصفحه بسهولة.

```bash
# بناء الموقع الساكن فورياً
php bin/eidcloud-site build ./content/ --out=./dist/
```

> "البساطة والأداء العالي هما مفتاح النجاح لأي موقع وثائق ومحتوى."
